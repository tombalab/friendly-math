# DejaVu Sans (PDF — polskie znaki)

Karta pracy PDF wymaga czcionki z pełnym zestawem polskich znaków diakrytycznych.

## Instalacja (powtarzalna)

1. **Zalecane:** plik `DejaVuSans.ttf` w tym katalogu (dołączony w repozytorium po sklonowaniu).

## Pobranie ręczne

Oficjalna paczka: [DejaVu Fonts 2.37](https://dejavu-fonts.github.io/Download.html)  
Skopiuj `ttf/DejaVuSans.ttf` do `assets/fonts/DejaVuSans.ttf`.
